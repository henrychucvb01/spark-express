# Demo menu photography

These are generated sample images for the fictional faculty demo, not photographs of actual district meals. The menu labels them as sample imagery.

Created with the built-in image generation tool and optimized to 1200 × 800 WebP for the website:

- `chicken-rice.webp`: herb-roasted sliced chicken breast over brown rice with steamed broccoli, on an off-white ceramic plate.
- `chickpea-salad.webp`: chickpeas, crisp greens, cucumber, cherry tomatoes, and carrot ribbons in an off-white ceramic bowl.

Shared prompt direction: photorealistic professional food photography; realistic adult café lunch portions; warm natural window light; a pale cream tabletop and subtle navy linen; a close three-quarter overhead composition with crop margins. No text, logos, prices, people, watermarks, or collages. Each asset depicts one meal. No nutrition information was generated.
